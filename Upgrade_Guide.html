Upgrade Guide

Do not remove the extension first. Keep the same unpacked extension entry and replace files in its existing folder so Chrome can retain recipients and settings.

Steps

  1. Note the installed version and select Back up all settings to save recipients, schedules, notifications, language, and other settings.
  2. Select Copy source folder to retrieve the path saved during installation. If it was never saved, locate the original folder and add it to the note first.
  3. Select Download latest vX.Y.Z to get a versioned ZIP such as CGUPostalChecker-v1.2.1.zip.
  4. Select Open Downloads folder, extract the ZIP, and confirm the extension folder directly contains manifest.json.
  5. Copy every new file over the saved source folder. Do not update only some files.
  6. Do not remove the extension. Select Open Chrome extensions in Settings.
  7. Find the extension at chrome://extensions/ and select Reload.
  8. Verify the version, language, recipients, and monitoring options.
  9. Select Check now. The upgrade is complete when no red ! appears and every recipient has a recent check time.

If settings disappear

This usually means the old extension was removed before loading the new copy. Open Settings, select Import settings, and choose the settings backup JSON created before upgrading. A history JSON export is for reference only and is different from a settings backup.
