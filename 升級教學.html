升級教學

不要先按「移除」外掛。保留同一個未封裝外掛項目並覆蓋原資料夾，Chrome 儲存的收件人與設定通常會保留。

升級步驟

  1. 在設定頁記下「已安裝版本」，並可先從紀錄頁匯出 JSON 備份。
  2. 按「複製程式目錄」，取得安裝時記錄的原始資料夾路徑。若尚未記錄，請先找出原資料夾並填入備忘。
  3. 按「下載最新版 vX.Y.Z」，取得檔名包含版本號的 ZIP，例如 CGUPostalChecker-v1.1.1.zip。
  4. 按「開啟下載資料夾」，解壓縮 ZIP，確認外掛資料夾直接包含 manifest.json。
  5. 把新版資料夾內的所有檔案覆蓋到第 2 步的原始程式資料夾。不要只覆蓋部分檔案。
  6. 不要按「移除」。回到設定頁按「開啟 Chrome 擴充功能頁」。
  7. 在 chrome://extensions/ 找到本外掛並按「重新載入」。
  8. 開啟設定，確認版本、語言、收件人與監控設定仍正確。
  9. 按「立即查詢一次」。若沒有紅色 ! 且每位收件人都有最新查詢時間，即完成升級。

若設定消失

通常代表刪除了舊外掛後又重新載入，造成新的擴充功能識別狀態。請重新設定收件人；先前匯出的 JSON 目前只供查閱，不能直接匯入設定。

Upgrade Guide

Do not remove the extension first. Keep the same unpacked extension entry and replace files in its existing folder so Chrome can retain recipients and settings.

Steps

  1. Note the installed version and optionally export the history JSON as a backup.
  2. Select Copy source folder to retrieve the path saved during installation. If it was never saved, locate the original folder and add it to the note first.
  3. Select Download latest vX.Y.Z to get a versioned ZIP such as CGUPostalChecker-v1.1.1.zip.
  4. Select Open Downloads folder, extract the ZIP, and confirm the extension folder directly contains manifest.json.
  5. Copy every new file over the saved source folder. Do not update only some files.
  6. Do not remove the extension. Select Open Chrome extensions in Settings.
  7. Find the extension at chrome://extensions/ and select Reload.
  8. Verify the version, language, recipients, and monitoring options.
  9. Select Check now. The upgrade is complete when no red ! appears and every recipient has a recent check time.

If settings disappear

This usually means the old extension was removed before loading the new copy. Configure recipients again. The exported history JSON is for reference and cannot currently restore settings.
