升級教學

不要先按「移除」外掛。保留同一個未封裝外掛項目並覆蓋原資料夾，Chrome 儲存的收件人與設定通常會保留。

升級步驟

  1. 在設定頁記下「已安裝版本」，並可先從紀錄頁匯出 JSON 備份。
  2. 按「下載最新版」，取得 GitHub main 分支 ZIP。
  3. 關閉外掛 Popup；將 ZIP 解壓縮到暫存資料夾。
  4. 確認解壓縮內容直接包含 manifest.json。
  5. 把新版資料夾內的所有檔案覆蓋到原外掛資料夾。不要只覆蓋部分檔案。
  6. 開啟 chrome://extensions/，找到本外掛並按「重新載入」。
  7. 開啟設定，確認版本、語言、收件人與監控設定仍正確。
  8. 先按「立即查詢一次」。若圖示沒有紅色 ! 且各收件人有最新查詢時間，即完成升級。

若設定消失

通常代表刪除了舊外掛後又重新載入，造成新的擴充功能識別狀態。請重新設定收件人；先前匯出的 JSON 目前只供查閱，不能直接匯入設定。

Upgrade Guide

Do not remove the extension first. Keep the same unpacked extension entry and replace files in its existing folder so Chrome can retain recipients and settings.

Steps

  1. Note the installed version and optionally export the history JSON as a backup.
  2. Select Download latest to get the GitHub main-branch ZIP.
  3. Close the popup and extract the ZIP to a temporary folder.
  4. Confirm the extracted extension folder directly contains manifest.json.
  5. Copy every new file over the existing extension folder. Do not update only some files.
  6. Open chrome://extensions/ and select Reload for this extension.
  7. Open Settings and verify the version, language, recipients, and monitoring options.
  8. Select Check now. The upgrade is complete when no red ! appears and every recipient has a recent check time.

If settings disappear

This usually means the old extension was removed before loading the new copy. Configure recipients again. The exported history JSON is for reference and cannot currently restore settings.
