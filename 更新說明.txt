v1.2.0 更新內容

- 診斷檔案不綁定 Gmail 或任何特定郵件服務，由使用者自行選擇寄送方式。

v1.1.1 更新內容
- 修正第一位收件人因頁面尚未準備而被跳過。

- 首次安裝自動偵測 Chrome 語言；繁體中文語系預設繁中，其餘一律預設英文。
- 下載最新版時自動使用含版本號的檔名，例如 CGUPostalChecker-v1.1.1.zip。
- 新增開啟 Chrome 擴充功能頁、開啟下載資料夾與原始程式資料夾備忘。
- 每天自動檢查 GitHub 最新版本，並提供下載與雙語升級教學。
- 新增英文檔名的 User Guide、Upgrade Guide、Quick Installation 與 Release Notes；英文介面的相關按鈕會直接開啟英文文件。

v1.2.2 changes
- Removes the invalid optional `debugger` permission that caused a warning on `chrome://extensions/`.
- Creates error-page images locally in the CGU query page without Chrome's debugger API.
- Localizes the extension card name, description, and action title: Traditional Chinese for a Traditional Chinese Chrome interface and English for all other interface languages.

v1.2.1 changes
- After a diagnostic JSON/ZIP download, displays the developer email address and asks whether to open the system's default email application.
- Prefills the recipient, subject, extension version, and diagnostic filename without depending on Gmail or another specific provider.
- Reminds the user to attach the downloaded report manually; the extension never claims to attach local files automatically.

v1.2.0 changes
- Adds complete settings backup and validated import for recipients, schedules, notifications, language, and the source-folder note.
- Adds diagnostic JSON/ZIP reports containing extension and Chrome versions, query-field status, error logs, and the latest query result.
- Adds optional error-page screenshots. The feature is off by default.
- Adds the author's email address and website.
- Keeps diagnostic files independent of Gmail or any specific email provider.

v1.1.1 changes
- Prevents the first recipient from being skipped before the page is ready.
- Retries failed recipient queries three times and preserves the actual error.
- Shows a red ! badge and recipient-level details when any query fails.
- Clears the error badge only after every recipient succeeds.
- Adds Traditional Chinese and English interfaces, descriptions, and guides.
- Detects the Chrome language on first install; Traditional Chinese locales default to Chinese and all other locales default to English.
- Saves GitHub downloads with a versioned filename such as CGUPostalChecker-v1.1.1.zip.
- Adds buttons for the Chrome extensions page and Downloads folder, plus a saved source-folder note.
- Checks GitHub daily and provides download links plus a bilingual upgrade guide.
- Adds English-named User Guide, Upgrade Guide, Quick Installation, and Release Notes files; documentation buttons in the English interface open the English files directly.
