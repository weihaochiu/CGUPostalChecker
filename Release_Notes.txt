CGU Postal Mail Checker v1.2.0 | Release Notes

- Adds complete settings backup and validated import.
- Adds diagnostic JSON and ZIP reports with version, browser, query-field, error-log, and latest-result information.
- Adds optional query-page screenshots on errors. The feature is off by default and requests optional debugger permission only when enabled.
- Adds author contact information and website.
- Keeps diagnostic files independent of Gmail or any specific email provider.

- Prevents the first recipient from being skipped before the page is ready.
- Retries failed recipient queries three times and preserves the actual error.
- Shows a red ! badge and recipient-level details when any query fails.
- Clears the error badge only after every recipient succeeds.
- Adds Traditional Chinese and English interfaces, descriptions, and guides.
- Detects the Chrome language on first installation; Traditional Chinese locales default to Traditional Chinese and all other locales default to English.
- Saves GitHub downloads with a versioned filename such as CGUPostalChecker-v1.1.1.zip.
- Adds buttons for the Chrome extensions page and Downloads folder, plus a saved source-folder note.
- Checks GitHub daily and provides download links plus upgrade instructions.
- Adds English-named documentation files so English readers do not need to open Chinese filenames.
- Opens English-named user and upgrade guides from documentation buttons whenever the interface language is English.
