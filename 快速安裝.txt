長庚大學自動查詢郵件 v1.1.1｜快速安裝

1. 解壓縮 ZIP 到固定資料夾。
2. 開啟 chrome://extensions/ 並啟用「開發人員模式」。
3. 按「載入未封裝項目」，選擇直接包含 manifest.json 的資料夾。
4. 登入 https://www4.is.cgu.edu.tw/postal/studentletter.aspx
5. 開啟外掛設定，選擇語言、新增收件人，並在「原始程式資料夾備忘」記錄第 1 步的路徑。
6. 儲存設定後按「立即查詢一次」，確認沒有紅色 !，再開始監控。

首次安裝：繁體中文 Chrome 預設繁中，其餘語言預設英文。

CGU Postal Mail Checker v1.1.1 | Quick installation

1. Extract the ZIP to a permanent folder.
2. Open chrome://extensions/ and enable Developer mode.
3. Select Load unpacked and choose the folder containing manifest.json.
4. Sign in at https://www4.is.cgu.edu.tw/postal/studentletter.aspx
5. Open Settings, choose a language, add recipients, and save the folder from step 1 in Source folder note.
6. Save, then select Check now. Confirm that no red ! appears before starting monitoring.

First install: Traditional Chinese Chrome locales default to Chinese; all others default to English.
