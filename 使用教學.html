長庚大學自動查詢郵件 v1.2.1

安裝

  1. 解壓縮 ZIP 到固定資料夾，例如 C:\Program Files\Google\ChromeExtensions\CGUPostalChecker。
  2. 開啟 chrome://extensions/，啟用「開發人員模式」。
  3. 按「載入未封裝項目」，選擇直接包含 manifest.json 的資料夾。
  4. 開啟長庚郵件查詢頁並登入。
  5. 在設定頁選擇語言、新增收件人並儲存。
  6. 在「原始程式資料夾備忘」記錄第 1 步的固定路徑；Chrome 無法日後自動找回該原生路徑。
  7. 按「立即查詢一次」，確認每位收件人都成功，再開始監控。

首次安裝會偵測 Chrome 語言：繁體中文語系預設繁中，其餘一律預設英文；手動選擇後會保留。

圖示與通知

  • 藍色數字：目前郵件件數。
  • 紅色 !：至少一位收件人查詢失敗；請開啟 Popup 或紀錄查看原因。
  • 沒有數字：成功查詢且為 0 件，或已關閉件數顯示。
  • 本外掛不會監聽 Gmail；通知信到達後，要等下一輪查詢才會提醒。

GitHub 更新

預設每天檢查 GitHub 最新版本。下載檔名會包含版本號，例如 CGUPostalChecker-v1.2.1.zip。未封裝外掛無法安全地自動覆寫程式；真正自動安裝更新需要發布到 Chrome Web Store。

升級流程

  1. 按「複製程式目錄」取得已記錄的原始路徑。
  2. 按「下載最新版」及「開啟下載資料夾」，解壓縮 ZIP。
  3. 將新版全部檔案覆蓋到原始資料夾。
  4. 按「開啟 Chrome 擴充功能頁」，不要移除外掛，直接按「重新載入」。
  5. 確認版本與設定後執行一次立即查詢。

故障排除

  • 紅色 !：確認查詢頁仍登入，再按「立即查詢一次」。
  • 收到通知信但外掛沒提醒：比較信件時間與上次查詢時間。
  • 更新失敗：確認可連線 GitHub，稍後手動重試。

備份與診斷

  • 「備份全部設定」保存收件人、排程、通知、語言與原始程式資料夾備忘，不含學校帳號密碼。
  • 「匯入設定」會先驗證本外掛產生的 JSON 再覆蓋目前設定。
  • 診斷 JSON／ZIP 包含外掛與 Chrome 版本、查詢欄位、錯誤紀錄及最近查詢結果。下載後會顯示 weihao.chiu@gmail.com，並詢問是否開啟系統預設郵件程式；請自行附加診斷檔案。
  • 錯誤截圖預設關閉；啟用時才要求可選的除錯權限，且只擷取長庚查詢頁。
  • 診斷內容或截圖可能包含姓名、郵件資料及本機路徑，分享前請先確認。

CGU Postal Mail Checker v1.2.1

Installation

  1. Extract the ZIP to a permanent folder such as C:\Program Files\Google\ChromeExtensions\CGUPostalChecker.
  2. Open chrome://extensions/ and enable Developer mode.
  3. Select Load unpacked and choose the folder containing manifest.json.
  4. Open the CGU postal page and sign in.
  5. Choose a language, add recipients, and save settings.
  6. Save the permanent folder from step 1 in Source folder note; Chrome cannot recover the native path automatically later.
  7. Select Check now; confirm every recipient succeeds, then start monitoring.

On first installation, Traditional Chinese locales default to Chinese; every other locale defaults to English. Manual selections are preserved.

Icon and notifications

  • Blue number: current mail count.
  • Red !: at least one recipient failed; open the popup or history for details.
  • No badge: a successful zero result, or the count badge is disabled.
  • The extension does not monitor Gmail. A notification email may arrive before the next query.

GitHub updates

The extension checks GitHub daily and saves a versioned filename such as CGUPostalChecker-v1.2.1.zip. An unpacked extension cannot safely overwrite itself; fully automatic installation requires Chrome Web Store distribution.

Upgrade workflow

  1. Select Copy source folder to retrieve the saved path.
  2. Select Download latest and Open Downloads folder, then extract the ZIP.
  3. Copy every new file over the original source folder.
  4. Select Open Chrome extensions. Do not remove the extension; select Reload.
  5. Verify the version and settings, then run one manual check.

Troubleshooting

  • Red !: verify the postal page is signed in, then select Check now.
  • Email received but no alert: compare the email time with the last query time.
  • Update check failed: verify GitHub connectivity and retry later.

Backup and diagnostics

  • Back up all settings saves recipients, schedules, notifications, language, and the source-folder note without university credentials.
  • Import settings validates a JSON backup created by this extension before replacing settings.
  • Diagnostic JSON/ZIP files contain extension and Chrome versions, query-field status, error logs, and the latest query result. After downloading, the extension displays weihao.chiu@gmail.com and can open the system's default email application; attach the report manually.
  • Error screenshots are off by default. Enabling the option requests the optional debugger permission for the CGU query page only.
  • Diagnostics and screenshots may contain names, mail details, and a local path. Review them before sharing.
